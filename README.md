# トップニュースバー
特徴

大半のページ上部にニュース、天気予報、為替を表示します。

※表示できないサイト※

chrome://newtab（新しいタブ）

他にもありましたらudeudeArm32X@proton.meまでお知らせください。

##使い方

1 topnewsbar.zipファイルをダウンロード

2 解凍する

3 アドレスバーにchrome://extentionsと打つ

4 「パッケージ化されていない拡張機能を読み込む」を押す
5 解凍したファイルを読み込む
